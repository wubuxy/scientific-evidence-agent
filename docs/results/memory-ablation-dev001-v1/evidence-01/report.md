# 基于QASPER与ArxivDIGESTables的论文研究Agent评测方案对比与建议

状态：待研究者审核

- QASPER数据集包含5,049个由NLP从业者根据论文标题和摘要撰写的问题，答案及支撑证据需从全文中检索，旨在评估模型在单篇论文内进行复杂推理和信息检索的能力。 [ev_e0f32680f329986fc84dcbeb2a560f36]
- ArxivDIGESTables数据集包含2,228个文献综述表格，涵盖7,542篇论文，任务是将多篇输入论文综合为具有统一schema（列）和值的表格，旨在评估跨论文信息抽取、模式生成与综合对比能力。 [ev_72253f43baf2a2316b3433ac10ec2fe1]
- [推断] 两个任务的指标不能直接横向排名，因为QASPER衡量的是单篇文档内的问答F1分数（依赖全文检索与推理），而ArxivDIGESTables衡量的是多文档表格生成的准确性与schema一致性，两者任务目标、输入输出形式及评估基准完全不同。 [ev_e0f32680f329986fc84dcbeb2a560f36, ev_72253f43baf2a2316b3433ac10ec2fe1]
  适用范围：基于两篇论文对任务定义（单篇QA vs 多篇表格生成）和评估目标（F1 vs 表格重建/人工评估）的描述推断，不同任务范式下的指标不具备直接可比性。
- [推断] 当前产品能力中，单篇论文深度问答有QASPER作为评测依据，跨论文结构化对比有ArxivDIGESTables作为依据，但关于“提出有依据的研究建议”这一能力，两篇论文均未提供直接的评测数据集或指标。 [ev_e0f32680f329986fc84dcbeb2a560f36, ev_72253f43baf2a2316b3433ac10ec2fe1]
  适用范围：QASPER仅涉及问题回答与证据定位，ArxivDIGESTables仅涉及表格合成，原文未提及针对“研究建议生成”的评测任务或数据。
- QASPER的参考答案由一组独立的NLP从业者提供，并附带支撑证据；ArxivDIGESTables的参考表格是从ArXiv论文中提取的真实文献综述表格。 [ev_e0f32680f329986fc84dcbeb2a560f36, ev_72253f43baf2a2316b3433ac10ec2fe1]

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取QASPER测试集子集（如100题）验证单篇问答，选取ArxivDIGESTables测试集子集（如50表）验证跨篇表格生成，并设计一个小型‘建议生成’人工评测集（基于现有论文结论推导）。
  依据：结论 1, 2, 4
  假设：假设QASPER和ArxivDIGESTables的测试集划分可用且能代表各自任务难度。；假设‘建议生成’能力可通过人工构造少量案例进行初步定性评估。
  验证计划：1. 数据划分：从两数据集官方测试集中随机抽样，确保不泄露训练数据。2. 人工检查：邀请领域专家对模型输出的答案证据链、表格schema合理性及建议的逻辑性进行打分。3. 失败计数：统计无法找到证据、表格结构错误、建议无依据的案例数量，设定阈值（如准确率<80%视为失败）。
- 建立跨任务能力映射矩阵，明确区分单篇推理、跨篇综合与建议生成的边界，避免将单一高分误判为全能。
  依据：结论 3, 4
  假设：假设产品需要同时具备三种能力，且当前评测体系存在混淆风险。
  验证计划：制定明确的评测报告模板，强制要求分别报告三项能力的得分，并在报告中显式说明各指标的适用范围，禁止跨任务排名。
- 针对‘建议生成’能力缺口，设计基于反事实推理的评测用例，要求模型在给定论文结论下提出合理的后续研究方向，并由专家验证其可行性。
  依据：结论 4
  假设：假设现有的QA和表格生成任务不足以覆盖‘建议生成’所需的创造性推理能力。
  验证计划：收集10-20篇高影响力论文，人工编写‘理想建议’作为参考，让模型生成建议，通过专家盲审计算与参考建议的重合度或逻辑自洽性评分。

## 限制与待验证问题

- 本报告仅基于提供的两篇论文摘要与引言部分，未获取完整的实验设置、具体基线模型性能数据及详细的评估协议细节。
- 关于‘提出有依据的研究建议’能力的评测，原文未提供相关数据集或指标，该领域目前缺乏直接的评测依据。
- 无法验证当前最强模型在两数据集上的最新表现，报告中的性能差距（如QASPER的27点F1差距）仅反映论文发表时的基线情况。
- ArxivDIGESTables的具体自动评估指标DECONTEXT EVAL的计算细节未在回读片段中完全展开，仅知其用于对齐表格元素。
