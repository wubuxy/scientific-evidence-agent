# 基于QASPER与ArxivDIGESTables的论文研究Agent评测方案对比与建议

状态：待研究者审核

- QASPER数据集包含5,049个由NLP从业者撰写的问题，这些问题仅基于论文的标题和摘要提出，但答案需从全文中查找，并由另一组从业者提供答案及支撑证据。 [ev_dd816cb717387031d4d854ae3c8a3260]
- ArxivDIGESTables数据集包含2,228个文献综述表格，这些表格综合了7,542篇ArXiv论文，旨在评估语言模型将多篇论文合成为结构化表格（包含schema和values）的能力。 [ev_1ab545c3d468fb8c48489efb9790eb13]
- [推断] QASPER任务验证的是单篇论文内的信息检索与推理能力，要求模型在长文档中找到分散的证据来回答特定问题；而ArxivDIGESTables验证的是跨多篇论文的文献综合与结构化生成能力。 [ev_dd816cb717387031d4d854ae3c8a3260, ev_1ab545c3d468fb8c48489efb9790eb13]
  适用范围：基于两篇论文对各自任务定义的描述：QASPER强调'anchored in research papers'且答案在全文中，ArxivDIGESTables强调'synthesizing information across a large set of documents'并生成表格。
- [推断] 两个任务的指标不能直接横向排名，因为QASPER衡量的是问答准确率（如F1），关注单点信息的提取与证据匹配；而ArxivDIGESTables衡量的是表格生成的完整性与一致性（使用DECONTEXT EVAL），关注多源信息的结构化整合。 [ev_dd816cb717387031d4d854ae3c8a3260, ev_1ab545c3d468fb8c48489efb9790eb13]
  适用范围：推断基于两者任务目标（QA vs Table Synthesis）和评估方法（F1/人类差距 vs DECONTEXT EVAL/人工评估）的本质差异，原文未提供跨任务比较数据。
- [推断] 当前产品能力中，针对‘提出有依据的研究建议’这一需求，两篇论文均未提供直接的评测依据或数据集支持。 [ev_dd816cb717387031d4d854ae3c8a3260, ev_1ab545c3d468fb8c48489efb9790eb13]
  适用范围：QASPER聚焦于事实性问答，ArxivDIGESTables聚焦于现有信息的表格化总结，原文均未涉及生成新的研究假设或建议的任务定义。

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取QASPER子集测试单篇深度问答，选取ArxivDIGESTables子集测试跨篇表格生成，并设计人工检查流程验证‘研究建议’的合理性。
  依据：结论 1, 2, 5
  假设：QASPER和ArxivDIGESTables的数据集格式可直接用于评测脚本开发；人工检查是评估‘研究建议’质量的最可行方式，因缺乏自动化标准
  验证计划：1. 数据划分：从QASPER随机抽取100题，从ArxivDIGESTables抽取50个表格作为测试集。2. 运行Agent生成结果。3. 人工检查：对QASPER结果核对证据链，对ArxivDIGESTables结果核对表格一致性，对生成的建议进行专家打分。4. 失败计数：统计无法找到证据、表格结构错误及建议无依据的案例数。
- 针对‘研究建议’能力缺口，建立基于文献综述的新颖性与可行性的人工评估标准。
  依据：结论 5
  假设：现有的文献综述表格（ArxivDIGESTables）可作为生成建议的背景知识来源；专家能够区分合理的推断与无依据的猜测
  验证计划：收集Agent基于ArxivDIGESTables表格生成的建议，邀请领域专家根据‘新颖性’、‘逻辑连贯性’和‘文献支持度’三个维度进行评分，设定阈值判定通过与否。

## 限制与待验证问题

- 本报告仅基于提供的两篇论文摘要部分，未获取完整的实验设置、具体模型性能数据及详细的评估协议。
- 关于‘提出有依据的研究建议’的评测能力，原文未提供相关数据集或任务定义，该领域目前处于未知状态。
- 无法直接比较QASPER与ArxivDIGESTables的模型性能排名，因任务类型、输入输出形式及评估指标本质不同。
- 报告中关于任务适用范围的推断基于摘要描述，可能未涵盖论文中提到的所有细微限制或扩展场景。
