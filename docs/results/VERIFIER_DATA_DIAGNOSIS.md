# 证据核验器的数据与误判诊断

日期：2026-11-06。**数据质量确实值得优先处理：公开标签审计中的更正建议涉及当前 7 条训练样本、1 条校准样本和 6 条测试样本，另有一条需要定位到具体文档的测试更正。但现有证据不能把错误放行全部归因于数据。** 固定预测的标签敏感性分析没有消除支持精确率不足的问题，判定规则和难例覆盖也需要独立对照。

这是对已观察实验的事后诊断。原始训练数据、gold、预测、预注册门槛和 [v2 主结果](SCIFACT_VERIFIER_SCALE_V2.md) 保留。下列重评分不代表重新训练后的成绩，也不替换主结果。

## 数据构造检查

## 标签疑点与已有审计

先检查了三个 LoRA 种子共同错的 23 对，以及按固定散列、每类 10 对抽取的训练样本。发现以下例子后，检索到 [Sylvestre 的 BioNLP 2026 审计](https://aclanthology.org/2026.bionlp-1.9.pdf)，其中也列出这些问题。

| 样本 | 原始标签 | 摘要与声明之间的问题 | 当前地位 |
|---|---|---|---|
| train 933 / 14711483 | 支持 | 声明说用药量增加；摘要报告部分时段减少，另一些时段没有显著差异 | 训练监督疑点，已有公开勘误建议 |
| dev 1385 / 306006 | 支持 | 声明说增强信号；摘要说增强 cSMAC 形成会降低刺激能力 | 已有公开的标签反向更正建议 |
| dev 593 / 19675911 | 支持 | 声明说发病率下降 10%；摘要说随时间没有变化 | 已有公开的标签反向更正建议 |
| dev 808 / 36606083 | 支持 | 声明说终止事件依赖序列；摘要结果说不依赖相关顺式序列 | 已有公开的标签反向更正建议 |

文献采用一位人工标注者结合 LLM 复核，作者明确要求独立复核。因此这里将其作为外部更正建议，不当作新的确定真值。与本项目数据相交的条目完整保存在 [data-diagnosis.json](scifact-verifier-scale-v2/data-diagnosis.json)；来源文件、固定提交和许可见[审计资料](../dataset-manifests/scifact-audit-bionlp2026/README.md)。这些命中数量也不能用来估计整个数据集的错标率。

另一个发现是，正确的文档标签不保证所标 rationale 足够。例如 train 78 的完整摘要确实描述 caspase-11 促进某类吞噬体与溶酶体融合，但标注句主要描述另一类细菌的例外。直接把所有 gold rationale 当作高质量推理监督会引入新的问题；rationale 训练需要单独审核。

## 固定预测的标签敏感性

对未微调 7B、三个 LoRA 种子和 MiniCheck 应用同一组更正建议，模型输出保持原样，分母保持 128 对。只将来源中范围明确、原始标签匹配的 6 条测试建议应用到一个独立评分视图。NEI 仍保留在分母中，参与 insufficient 和不支持类评分。

| 方法 | 原始 Macro F1 | 更正建议视图 Macro F1 | 原始支持精确率 | 更正建议视图支持精确率 |
|---|---:|---:|---:|---:|
| 未微调 7B BF16 | 0.5814 | 0.5697 | 80.0% | 73.3% |
| LoRA 三种子均值 | 0.7460 | 0.7511 | 76.0% | 71.6% |
| MiniCheck | 不适用 | 不适用 | 91.9% | 89.2% |

更正能把部分原来被扣分的合理预测改判正确，也会把原来得分的错误支持暴露出来。LoRA 的 Macro F1 只增加约 0.51 个百分点，支持精确率反而下降。**“测试标签有错”并不能推出“模型实际已经足够好”。** 对训练标签更正后模型会发生什么变化，需要重新训练才能回答。

声明 597 的外部 JSON 留空 doc ID，却称其为文档级问题。完整摘要核对显示，12779444 讨论死亡率，另外两篇摘要报告发病率。因此只针对 12779444 增加单独情景；该情景下 LoRA 平均 Macro F1 为 0.7444、支持精确率为 69.7%。这进一步说明不能把声明级更正盲目应用到所有引用文档，也不能只报告分数最高的重评分版本。

## 真实错误和判定规则

三个 LoRA 种子有 23 对共同错误，涉及 13 个原始矛盾标签、5 个不足标签、5 个支持标签；只有 19 对在种子间改变了预测类别。共同错题中包含上述标签疑点，也包含明确的模型错误：将论文中的对照组效果套到目标组、将一个化合物稳定分子结构与破坏染色体稳定性混为一谈，以及把相关人群或相关疾病当作声明限定的人群或疾病。

原三分类规则是 A/B/C 取最高分。三个 LoRA 种子分别有 2、4、2 条错误支持的 A 分数低于 0.5。最高分并不必然超过一半，这为不够确定的支持判断提供了放行路径。A/B/C 归一化分数仍不是已校准置信度。

为检查规则影响，用保存的分数做了探索回放：只在原 65 对校准集上选择经验错误放行率不超过 5%、支持召回率最高的阈值，再应用到已观察测试。每个模型独立校准，不共用数值阈值。

| 方法 | 校准所选阈值 | 旧测试支持召回率 | 旧测试错误放行率 |
|---|---:|---:|---:|
| 未微调 7B | 0.1472 | 78.7% | 11.1% |
| LoRA seed 20261106 | 0.7010 | 76.6% | 12.3% |
| LoRA seed 20261107 | 0.4683 | 83.0% | 13.6% |
| LoRA seed 20261108 | 0.6569 | 83.0% | 9.9% |
| MiniCheck | 0.4376 | 74.5% | 4.9% |

这些是原始标签下的事后诊断，不是新的确认性实验。校准集只有 43 个不支持样本，而且其中也发现一个公开标签疑点；经验 5% 无法保证测试或真实使用时的错误率。阈值有帮助，但单靠它没有消除差距。

训练目标对三个类别使用同一种交叉熵，没有专门体现错误支持的代价；训练过程只记录了不同 minibatch 的 loss，没有训练集和验证集随 checkpoint 变化的统一评估。因此暂时无法判断欠拟合、过拟合或适配器容量哪个是主因，不能仅凭训练不足一遍就断言需要多训。

## 下一步优先级

| 假设 | 当前证据 | 下一项可区分原因的实验 |
|---|---|---|
| 原始标签噪声影响监督和评分 | 有具体源文本及外部审计支持 | 同样本、同顺序、同训练预算，仅修改经仲裁的训练标签 |
| 三分类决策不适合直接放行 | 存在低于 0.5 仍为最大类的错误支持 | 固定权重，比较原决策与独立校准支持阈值 |
| 数据缺少目标任务难例 | 错误涉及范围、对象和对照关系；尚无完整覆盖标注 | 同预算比较普通扩充和定向最小对照样本 |
| 类别分布影响矛盾识别 | 训练与测试矛盾占比不同 | 在清洗后的相同样本上比较自然采样与类别均衡采样 |
| 训练不足或过拟合 | 当前日志不能判别 | 固定数据，记录 64/128/256 步的训练及验证曲线 |

具体条件、数据隔离、预算和停止规则见[下一轮实验计划](../experiments/VERIFIER_DATA_EXPERIMENT_PLAN.md)。现阶段优先处理可定位的标签问题，再检验训练数据更正是否改善真实错误支持。

## 复现

服务器准备数据目录是 `/mnt/d/Ding/data/scifact/verifier-scale-v2-003`。将原始包路径传给 `--raw`；本地诊断副本和未标注复核材料保存在忽略目录 `test-results/verifier-data-diagnosis/`。

```powershell
python scripts/diagnose_verifier_data.py --data-dir test-results/verifier-data-diagnosis --raw test-results/verifier-data-diagnosis/scifact-data.tar.gz --output docs/results/scifact-verifier-scale-v2/data-diagnosis.json --review-dir test-results/verifier-data-diagnosis/review
python scripts/audit_verifier_scale.py
```

诊断脚本只使用 Python 标准库，检查原始包与冻结文件哈希，并独立复算原结果中的二分类指标和三分类 Macro F1。复核包包含 **83 对**，覆盖固定抽取的 30 对训练样本、共同错题、新增错误支持、正确对照及外部勘误候选。`blind-inputs.json` 不显示 gold、模型判断或拆分，`coordinator-key.json` 由协调者保管。人工标注和仲裁尚未完成；83 对不能写成已有人类标注的数据集。
