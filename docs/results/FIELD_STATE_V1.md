# 字段状态与有界补救 v1：工程验收

日期：2026-11-07。此轮验证生产控制器是否按约束工作，不是新的 Agent 质量实验，也没有增加训练或人工标签。

## 完成的能力

- 每篇论文的要求保留在运行台账中，模型不能通过删除要求来制造完成。
- 候选答案绑定本次回读证据及内容版本；答案或引用变化后旧核验失效。
- 仅对缺项发起有限补读；程序保留已填写内容与其引用，补救失败保留上一份有效报告。
- 模型核验区分支持、回答充分性、方法归属和实验阶段；所有意见待人工确认。
- 时间、步数和 token 限制共同控制停止；额外核验记账，超限不可进入工具重试。
- 工作台展示缺口、版本、原文入口和停止原因；填写率不标为正确率。

设计与 API 见 [FIELD_STATE.md](../FIELD_STATE.md)。

## 尚未证明

字段充分性、补救净收益、错误支持率和停止质量仍需人工标签与同预算对照。现有 92 条盲审主要校准声明支持，不能充当字段任务完成标签。API 默认 `off` 保持旧运行行为；工作台默认 `bounded` 是可切换的产品功能，不能把历史实验成绩转述为新控制器的收益。
