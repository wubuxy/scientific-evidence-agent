# Agent 架构第一轮：回读控制接通，证据记忆尚不能判为更好

2026-11-08。先验证已有搜索到回读控制，再只改变 memory_mode 做四次交错运行。资料仍是 QASPER 与 ArxivDIGESTables 两篇公开演示论文，问题、八项要求与六项报告标准沿用已见开发任务。没有使用保留集，没有模型训练，也没有增加预算重跑失败。

**结论：执行控制允许模型完成真实回读和交付；本次证据记忆模式有更多结构有效的交付，但没有解决浅读、重复阅读或语义混淆。默认模式保持不变。**

## 轨迹揭示的下一批问题

以下为查看轨迹后的开发诊断，不是盲审标签，不进入人工质量分数。

- **格式失败仍会消耗交付预算。** legacy-01 已读到正文后部，但第一份报告的 comparison_rows 是无法完整解析的嵌套 JSON 字符串；第二份输出达到当次输出上限，JSON 不完整，最终预算不足。保留失败，没有通过拼接或猜测补成有效报告。
- **结构记忆没有自动形成有效的阅读策略。** evidence-01 读完两篇前 80 行后，尝试以 line_count=120 重读，超过工具上限 100，两次参数错误消耗了一个模型轮次。evidence-02 增加六次搜索后，再次读取已读的两个 1–60 行窗口。
- **填写与正确性仍不同。** 两份 evidence 报告在“任务与输入输出”单元格把 QASPER 的标题摘要出题条件写成答题输入。所引原文 23–28、59–74 行已经区分出题与全文回答，说明至少该案例不能单纯归因于没有检索到信息。
- **报告可用与要求满足仍不同。** legacy-02 使用“任务范围 / 输入输出 / 标注性质”等替代列名，未填入八个固定要求字段；台账正确保留缺项并在报告末尾说明。正文含有相关信息，不应把 0/8 解释为整份报告完全没有内容，也不能自动猜测这些列完全等价于原要求。

## 人工评审材料

三份契约有效的正式对照报告进入两份独立材料包，每份报告使用原先六条任务标准。材料含完整报告、带行号的实际回读、两篇原文和空标签；不含条件名、费用、轨迹或模型评分。条件对应表只留给协调者。

本机生成位置为 `test-results/memory-ablation-dev001-v1/human-review/annotator-a.zip` 与 `annotator-b.zip`。分发各自 ZIP，不分发 coordinator-mapping.json；仓库已公开原始轨迹，评审者须避免事先查看，不能声称绝对无法猜到条件。

当前已完成人工标签为 **0**。语义指标在人工材料返回前保持 null。未交付的尝试仍留在四次实验分母；只对已交付报告的语义评分必须注明条件化范围。这批整报告标准与已有 92 条自然声明标注任务用途不同，不能相互替代。

## 下一轮选择

优先推进“每次行动关联缺口 + 按缺口装配已有证据”，保留本轮两个模式作对照。具体检验：

1. 在动作中显式记录目标字段和需要补足的信息，区分新证据获取、已读证据重载和答案修正；避免只根据字段是否非空调度。
2. 将已经读到的出题/答题、训练/评测等角色与阶段限定放入同一证据视图；摘要只作导航，引用仍绑定原文。
3. 对读取范围给出可执行的补充窗口与已覆盖范围，测量重复读取和非法参数；不要用“读得更深”代替任务质量。
4. 保留严格的报告解析。分段交付或定向格式修复若要采用，应另设实验，避免同时改变上下文、输出预算与报告结构。

这轮证据不足以支持增加多 Agent 或继续训练。下一条件须单独冻结、与同预算普通补搜/现有模式对照，再看人工支持与充分性标签。

## 复现与审计

```bash
python scripts/audit_architecture_study.py --root docs/results/grounding-gate-dev001-v1
python scripts/audit_architecture_study.py --root docs/results/memory-ablation-dev001-v1
```

审计逐字核对原文、证据 ID/版本、实际回读导出、输入/输出用量、固定要求与归档哈希。审计通过只表示记录一致，不等于研究任务正确。归档禁用 Git 换行转换，冻结文件按原字节保存。

`scripts/prepare_memory_study.py` 记录如何准备本次条件；同名目录已经存在时拒绝覆盖。新实验使用新目录及新计划。`run_research_case.py prepare --memory-mode legacy|evidence` 将条件写入 manifest，run 只读取冻结条件，不接受运行时切换。

重新生成空白评审包可使用：

```bash
python scripts/package_architecture_review.py --root docs/results/memory-ablation-dev001-v1 --out test-results/memory-review-new
```

包内匿名 ID 随机生成，重新生成后的 ZIP 哈希会不同；每次保留各自映射。它不会调用模型或生成评分。
