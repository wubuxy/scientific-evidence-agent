# QASPER 与 ArxivDIGESTables 在训练、评测与迁移条件上的对比分析

状态：待研究者审核

- QASPER 的数据构建由两部分人员完成：问题作者基于论文标题和摘要撰写问题，而独立的 NLP 从业者负责判断答案是否存在、提取证据片段并撰写答案。 [ev_58d1ee6b44c639e3b4671b86daf1ee48, ev_1c7cdfd0acbe4801e7550fc5df5163f8]
- ArxivDIGESTables 的数据集通过从 ArXiv 抓取并过滤约 250 万张表格得到，最终保留 2,228 张高质量表格，每张表格关联其源论文的全文及上下文引用。 [ev_1df29f33e5eae0eed2eae745fe770da9, ev_d6e1eec3a9cd45a70bd57c771d718500]
- QASPER 的评测指标为 Answer-F1（基于 span-level F1）和 Evidence-F1，系统输入包含论文全文，但题目作者仅看到标题和摘要，回答者需从全文检索证据。 [ev_fa163842112d43799aca8bc3c58e0fde, ev_58d1ee6b44c639e3b4671b86daf1ee48]
- ArxivDIGESTables 提出 DECONTEXT EVAL 框架，重点解决生成表格与参考表格之间因表述不同导致的 schema 对齐难题，而非直接比较数值精度。 [ev_1df29f33e5eae0eed2eae745fe770da9, ev_8c8ad7885327c93850b0e299ddb1773b]
- [推断] 两篇论文均未明确报告用于模型微调的具体训练数据划分细节或是否使用了额外标注进行监督微调；QASPER 提供了 train/val/test 划分，但未说明基线模型是否在该划分上进行了全量微调。 [ev_fa163842112d43799aca8bc3c58e0fde]
  适用范围：原文仅描述了数据集划分比例（2,593/1,005/1,451），未提供模型训练阶段的具体超参数或微调策略细节。
- [推断] QASPER 的 Answer-F1 与 ArxivDIGESTables 的 schema 对齐评分不具备直接可比性，前者衡量文本片段匹配度，后者衡量语义结构一致性，且任务目标（问答 vs 表格生成）不同。 [ev_fa163842112d43799aca8bc3c58e0fde, ev_8c8ad7885327c93850b0e299ddb1773b]
  适用范围：基于两文对评估指标定义的差异推断，两者任务范式与评估对象本质不同。

## 方案建议（尚未执行，待验证）

- 设计一个最小控制实验：在 QASPER 测试集上，固定模型架构，对比‘仅提供标题+摘要’与‘提供全文’两种输入条件下的 Answer-F1 变化，以量化全文检索对性能的提升。
  依据：结论 1, 3
  假设：模型能够处理变长输入；标题+摘要不足以回答所有问题
  验证计划：固定随机种子，运行两次实验（一次截断输入为标题+摘要，一次使用全文），记录 Answer-F1 差异；若差异小于 5%，则假设全文检索贡献有限。停止条件：实验重复 3 次结果一致或资源耗尽。
- 在 ArxivDIGESTables 子集上，尝试移除‘表格上下文引用’输入，观察 schema 对齐评分的变化，以评估上下文信息对表格生成的必要性。
  依据：结论 2, 4
  假设：上下文引用包含关键 schema 定义信息；模型在无上下文时仍能生成部分正确表格
  验证计划：选取 100 个样本，分别在有/无上下文条件下生成表格，计算 DECONTEXT EVAL 分数；若分数下降超过 10%，则确认上下文关键。失败计数：若 3 次运行中 2 次无显著差异，则假设上下文非必需。

## 限制与待验证问题

- 两篇论文均未提供具体的模型微调超参数或训练过程细节，无法直接复现其训练策略。
- QASPER 的评测依赖于人工标注的证据片段，若实际应用中缺乏此类标注，Evidence-F1 指标将失效。
- ArxivDIGESTables 的 DECONTEXT EVAL 框架针对特定表格生成任务设计，其 schema 对齐方法在其他结构化生成任务中的适用性未知。
- 两文均未讨论在完全 non-oracle 条件下（即答案可能不存在或信息不完整）的系统表现。
