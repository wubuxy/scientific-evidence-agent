# 基于QASPER与ArxivDIGESTables的Agent评测方案对比与建议

状态：待研究者审核

- QASPER 数据集旨在评估系统回答基于单篇论文复杂推理问题的能力，其问题生成于阅读标题和摘要后，答案需从论文多个段落中检索证据。 [ev_8d72db7e837a71d271381be8bb3b2f94, ev_fa7b01c661be07786563862329458662]
- QASPER 的基线评估包含“搜索准确率”（Search Accuracy）和“阅读准确率”（Reading Accuracy），前者衡量正确答案是否出现在预排序的上下文中，后者衡量在上下文存在时的提取性能。 [ev_8d72db7e837a71d271381be8bb3b2f94]
- ArxivDIGESTables 任务要求语言模型将科学文献综合为表格，并提出了 DECONTEXT EVAL 方法以自动对齐表格元素，即使表面形式不同也能评估底层方面的一致性。 [ev_3d94ad435ef54f4ebdcf229a65194064, ev_499df5164e5d01074ae172647a2b379a]
- ArxivDIGESTables 的研究发现，该任务受益于额外的上下文（如表格标题、文中引用）来支撑生成，且人工评估表明即使未能完全重构参考表格，生成的新颖方面仍可能有用。 [ev_3d94ad435ef54f4ebdcf229a65194064, ev_499df5164e5d01074ae172647a2b379a]
- [推断] QASPER 适合验证单篇论文内的信息检索与复杂推理能力，而 ArxivDIGESTables 适合验证跨段落/多源信息的结构化综合与表格生成能力。 [ev_8d72db7e837a71d271381be8bb3b2f94, ev_3d94ad435ef54f4ebdcf229a65194064]
  适用范围：基于两篇论文各自定义的任务目标（问答 vs 表格合成）及所需推理类型（单篇内多段推理 vs 结构化综合）推断。
- [推断] 两个任务的指标不能直接横向排名，因为 QASPER 衡量的是问答准确性（依赖预排上下文），而 ArxivDIGESTables 衡量的是表格重构与内容对齐质量，两者评估对象、输出形式及成功标准完全不同。 [ev_8d72db7e837a71d271381be8bb3b2f94, ev_3d94ad435ef54f4ebdcf229a65194064]
  适用范围：基于两篇论文定义的指标（Search/Reading Accuracy vs DECONTEXT EVAL 对齐度）及任务本质差异推断。

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取 QASPER 子集（50题）测试单篇推理，选取 ArxivDIGESTables 子集（20表）测试结构化综合，分别计算准确率与对齐得分。
  依据：结论 1, 3
  假设：子集能代表整体难度分布；现有工具可解析两数据集格式
  验证计划：划分开发/测试集（8:2），人工抽检10%样本确认答案/表格质量，记录失败案例（如答案缺失、表格错位）并分类统计。
- 引入人工检查环节：对 QASPER 答案进行‘证据链完整性’打分，对 ArxivDIGESTables 表格进行‘信息忠实度’与‘新颖性’双维度评估。
  依据：结论 2, 4
  假设：人工评估者具备领域知识；评分标准可操作化
  验证计划：制定评分量表（1-5分），培训2名评估员，计算Kappa一致性，不一致样本由第三方仲裁。
- 建立失败计数机制：定义‘硬失败’（无答案/表格为空）与‘软失败’（答案错误/表格错位），分别统计比例并关联具体错误类型。
  依据：结论 1, 3
  假设：失败类型可明确归类；日志系统可捕获生成过程
  验证计划：在评测脚本中嵌入错误分类逻辑，输出结构化报告（含失败ID、类型、原始输入输出）。

## 限制与待验证问题

- 仅基于两篇论文的公开描述，未获取完整实验数据或最新模型表现。
- QASPER 的‘搜索准确率’依赖预排上下文，无法直接反映端到端检索能力。
- ArxivDIGESTables 的人工评估标准未在原文中详细量化，难以复现精确阈值。
- 两任务均未明确支持跨论文比较的自动化评测流程，产品相关能力缺乏直接依据。
