# 基于QASPER与ArxivDIGESTables的Agent评测方案对比与建议

状态：待研究者审核

- QASPER 数据集包含5,049个由NLP从业者针对1,585篇论文标题和摘要提出的问题，答案及支撑证据需从全文中检索，旨在评估单篇文档内的复杂推理与信息检索能力。 [ev_93c4ebe9e1e5582ebeaaf2228a38f5d4, ev_553b234425db76dee49328125c2f942f]
- ArxivDIGESTables 数据集包含2,228个文献综述表格，涵盖7,542篇论文，任务被分解为“模式生成”（确定比较维度）和“值生成”（填充具体信息），旨在评估跨多篇论文的文献综合与结构化输出能力。 [ev_53e649cfe83b43b3df645dd20a0e43d6, ev_dd480f315ad8c0f4c0738fc14b86fd8a]
- [推断] 两个任务的指标不能直接横向排名，因为QASPER衡量的是单篇文档内基于证据的回答准确性（F1分数），而ArxivDIGESTables衡量的是跨文档表格生成的结构对齐度与内容有用性（DECONTEXT EVAL及人工评估），两者输入范围、输出形式及评估目标完全不同。 [ev_93c4ebe9e1e5582ebeaaf2228a38f5d4, ev_53e649cfe83b43b3df645dd20a0e43d6]
  适用范围：基于两篇论文对任务定义（单篇问答 vs 多篇表格合成）和评估方法（F1 vs 自动/人工对齐）的描述推断。
- [推断] 当前产品能力中，针对“提出有依据的研究建议”这一需求，两篇论文均未提供直接的评测数据或基准；QASPER仅验证了回答现有问题的能力，ArxivDIGESTables虽涉及生成新维度但未明确验证其作为研究建议的有效性。 [ev_93c4ebe9e1e5582ebeaaf2228a38f5d4, ev_53e649cfe83b43b3df645dd20a0e43d6]
  适用范围：基于原文仅报告了问答准确率和表格重建/生成质量，未提及对生成内容的创新性或建议价值的独立评估。
- QASPER的标注过程要求回答者提供支撑证据（文本、表格或图表），且55.5%的问题需要跨段落证据，这为验证Agent的证据引用能力提供了基础。 [ev_553b234425db76dee49328125c2f942f]
- ArxivDIGESTables引入了DECONTEXT EVAL方法，用于在表面形式不同的情况下对齐表格元素，并发现即使模型未能完全重建参考表格，其生成的新颖维度仍可能具有实用性。 [ev_53e649cfe83b43b3df645dd20a0e43d6, ev_dd480f315ad8c0f4c0738fc14b86fd8a]

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取QASPER子集（如50题）测试单篇问答与证据引用，选取ArxivDIGESTables子集（如20组表格）测试跨篇综合，并新增“建议生成”人工评估环节。
  依据：结论 1, 2, 4
  假设：假设QASPER和ArxivDIGESTables的数据格式可直接用于自动化评测脚本。；假设人工评估可以补充原文未覆盖的‘建议价值’维度。
  验证计划：1. 数据划分：从QASPER随机抽取50个需跨段证据的问题；从ArxivDIGESTables抽取20个包含多源信息的表格任务。2. 自动化检查：运行Agent生成答案/表格，计算F1（QASPER）和DECONTEXT对齐分（ArxivDIGESTables）。3. 人工检查：邀请领域专家对生成的‘研究建议’进行打分（相关性、创新性、可行性），记录失败案例（无依据、幻觉）。4. 失败计数：统计无法提供证据的问答数、表格结构错误数及无效建议数。
- 设计‘建议有效性’专项指标：在ArxivDIGESTables基础上，要求Agent不仅生成表格，还需基于表格差异提出改进方向，并由专家验证其是否构成有效研究建议。
  依据：结论 2, 4, 6
  假设：假设ArxivDIGESTables中的‘新颖维度’可作为研究建议的雏形。；假设专家能够区分‘有用的新维度’与‘有效的研究建议’。
  验证计划：1. 扩展任务：在表格生成后增加‘基于此表提出一个研究问题’步骤。2. 评估标准：制定包含‘逻辑连贯性’、‘未被现有文献覆盖’、‘可执行性’的评分量表。3. 对照实验：对比仅使用表格信息与结合全文信息的建议质量。4. 迭代优化：根据反馈调整提示词，直至建议采纳率达到阈值。
- 建立跨任务一致性检查机制：验证Agent在QASPER中提取的证据是否在ArxivDIGESTables的表格生成中被正确复用，以检测长上下文下的信息一致性。
  依据：结论 1, 2, 5
  假设：假设同一主题的多篇论文在两个数据集中存在重叠或关联。；假设Agent具备跨任务记忆或检索能力。
  验证计划：1. 样本筛选：寻找QASPER和ArxivDIGESTables中涉及相同核心概念或方法的论文对。2. 一致性测试：检查Agent在问答中引用的事实是否与表格中填写的值一致。3. 冲突分析：记录并分类不一致的案例（如版本更新、理解偏差）。4. 指标定义：计算‘跨任务事实一致性率’作为新的评测指标。

## 限制与待验证问题

- 本报告仅基于提供的两篇论文摘要与引言部分，未获取完整的实验设置、详细指标定义及最新模型结果。
- 关于“研究建议”能力的评测依据在两篇原文中均缺失，无法确认现有数据集是否支持该能力的量化评估。
- 未核实两篇论文中基线模型的具体性能数值，仅引用了相对差距描述。
- 无法判断当前最强模型在QASPER或ArxivDIGESTables上的实际表现，因原文发表时模型已迭代。
