# QASPER 与 ArxivDIGESTables 在训练、评测与迁移条件上的对比分析

状态：待研究者审核

- QASPER 数据集由 NLP 从业者作为提问者基于论文标题和摘要生成问题，再由另一组 NLP 从业者提供答案及证据（文本、表格或图表），实现了提问与回答的解耦。 [ev_3ec49140b9ba1a1ce67ecebfdda9699d, ev_479816f30ce3774b6498e0f29542f838]
- ArxivDIGESTables 任务要求将多篇输入论文综合为一个包含模式（列）和值的表格，其评估依赖于人工编写的参考表格，并开发了 DECON-TEXT EVAL 方法以对齐不同表面形式的表格元素。 [ev_748b8d7a102be79b5fed45819195c9ec, ev_6d8d77536a7510869d8841cc1150d537]
- QASPER 中 55.5% 的问题需要跨段落证据，13% 需要表格或图表；当前最佳模型在回答整篇论文问题和选择证据段落上分别落后人类 27 和 32 F1 分，表明这是未解决的问题。 [ev_479816f30ce3774b6498e0f29542f838, ev_58fa7aa540ec6db7d77c8a1bcfcd3810]
- ArxivDIGESTables 实验发现，即使模型未能完全重构参考表格，其生成的新颖方面仍可能有用；且该任务受益于额外的上下文（如表格标题、文中引用）来支撑生成。 [ev_748b8d7a102be79b5fed45819195c9ec, ev_6d8d77536a7510869d8841cc1150d537]
- [推断] QASPER 实验中使用了基于金标准证据的 oracle 设置，结果显示更好的预训练和领域适应可能有助于提升性能，但具体 oracle 与非 oracle 条件下的详细分数对比未在已读片段中明确给出。 [ev_58fa7aa540ec6db7d77c8a1bcfcd3810]
  适用范围：基于原文提到“experiment with oracles”及“better pretraining and domain-adaptation might be helpful”，推断存在 oracle 设置且对性能有潜在影响，但具体数值缺失。
- [推断] 两篇论文均未在当前回读范围内明确说明用于模型微调的具体训练数据划分策略（如开发集/测试集比例）或是否引入了新增标注用于微调，仅描述了数据集构建过程。 [ev_3ec49140b9ba1a1ce67ecebfdda9699d, ev_748b8d7a102be79b5fed45819195c9ec]
  适用范围：原文详细描述了数据收集（decoupled data collection）和构建流程，但未在已读部分提及具体的训练/验证/测试划分或微调所需的额外标注步骤。

## 方案建议（尚未执行，待验证）

- 设计一个最小控制实验：固定使用 QASPER 中的 100 个需要跨段落证据的问题，对比两种输入条件：(A) 仅提供问题与相关段落（模拟 Oracle 证据已知），(B) 仅提供问题与整篇论文（模拟 Non-Oracle）。
  依据：结论 3, 5
  假设：假设跨段落证据检索是主要瓶颈；假设 Oracle 条件下模型能利用已知证据显著提升 F1
  验证计划：固定项：模型架构、问题集合、评估指标(F1)。改动项：输入上下文范围（段落级 vs 全文级）。失败计数：若 A 组比 B 组 F1 提升小于 5%，则视为假设不成立。停止条件：完成 100 个问题测试或达到预设时间上限。
- 针对 ArxivDIGESTables 任务，尝试在输入中显式添加表格标题和文中引用作为额外上下文，观察其对表格重构准确率及新颖性评分的影响。
  依据：结论 4
  假设：假设额外上下文能显著改善生成质量；假设现有模型未充分利用此类元数据
  验证计划：固定项：输入论文集合、评估方法(DECON-TEXT EVAL + 人工)。改动项：输入是否包含表格标题和引用信息。失败计数：若添加上下文后重构准确率无提升或下降，则停止。停止条件：完成小规模样本（如 50 个表格）测试。
