# 基于QASPER与ArxivDIGESTables的Agent评测方案对比与建议

状态：待研究者审核

- QASPER 任务定义为：给定一篇论文和一个关于该论文的问题，系统需判断问题是否可回答，并输出一个或多个全文中的文本片段作为答案（或 yes/no/其他自由文本）。 [ev_bc7ec84985584f309e6f75eb54343613]
- QASPER 数据集包含标注的证据段落，用于辅助监督；其评估指标基于预测答案与参考答案的正确性匹配。 [ev_bc7ec84985584f309e6f75eb54343613]
- ArxivDIGESTables 任务定义为：将多篇输入论文综合为一个文献综述表格，其中行对应论文，列对应用于比较和对比这些论文的方面（schema），并填充相应值。 [ev_1f384bbf16156e1fa16018ac899eb5bc]
- [推断] 两个任务的指标不能直接横向排名，因为 QASPER 衡量单篇论文内的问答准确性（F1等），而 ArxivDIGESTables 衡量跨论文信息抽取与表格生成的质量，任务目标、输入规模与输出形式完全不同。 [ev_bc7ec84985584f309e6f75eb54343613, ev_1f384bbf16156e1fa16018ac899eb5bc]
  适用范围：基于两篇论文对任务定义与评估目标的描述差异推断
- [推断] QASPER 适合验证 Agent 在单篇论文内进行复杂推理、定位证据并生成准确答案的能力；ArxivDIGESTables 适合验证 Agent 跨多篇论文进行信息抽取、模式识别与结构化综合的能力。 [ev_bc7ec84985584f309e6f75eb54343613, ev_1f384bbf16156e1fa16018ac899eb5bc]
  适用范围：基于两篇论文任务定义的差异推断
- [推断] 当前两篇论文未提供对‘提出有依据的研究建议’这一产品能力的直接评测依据；该能力涉及从已读内容中推断未来方向，原文仅描述了现有任务与数据构建过程。 [ev_e5d202422582df352dfe9c5336de51f1, ev_7b7991646d56079b717784ef944e9a26]
  适用范围：基于原文摘要与引言部分未提及研究建议生成任务的推断

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取QASPER测试集子集（如50题）验证单篇问答，选取ArxivDIGESTables子集（如20组多论文输入）验证表格生成。
  依据：结论 1, 3
  假设：QASPER与ArxivDIGESTables数据可获取且格式兼容；Agent能处理两种不同输入输出格式
  验证计划：1. 数据划分：各取随机子集，确保覆盖不同难度/领域；2. 人工检查：由2名专家独立评分答案/表格质量，计算一致性；3. 失败计数：统计完全错误、部分错误及格式错误案例数。
- 针对‘研究建议’能力，设计基于已读内容的推断任务：要求Agent从QASPER/ArxivDIGESTables的论文元数据或结论段中提取潜在研究方向，并由专家评估其合理性。
  依据：结论 6
  假设：论文中包含足够的结论或讨论信息以支持建议生成；专家能有效评估建议的合理性与新颖性
  验证计划：1. 从两数据集各选10篇论文，提取结论段；2. 让Agent生成3条建议；3. 专家按相关性、可行性打分；4. 记录低分案例原因。
- 建立跨任务能力映射表，明确哪些Agent功能模块（如检索、推理、生成）分别由哪个任务验证，避免指标混用。
  依据：结论 4, 5
  假设：Agent架构模块化，可单独评估各组件；任务与能力之间存在清晰映射关系
  验证计划：1. 列出Agent核心模块；2. 对照两任务定义，标记每个模块被验证的任务；3. 识别未被覆盖的模块，补充针对性测试用例。
