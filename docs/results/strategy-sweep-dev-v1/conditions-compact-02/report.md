# QASPER 与 ArxivDIGESTables 在角色、训练划分、评测条件及迁移可行性上的对比分析

状态：待研究者审核

- QASPER 数据集中，问题由仅阅读标题和摘要的 NLP 从业者撰写，答案由另一组 NLP 从业者提供并附带证据；系统输入为全文，但问题构建者未接触全文。 [ev_485758ab3111644a7881713ce943f86b]
- ArxivDIGESTables 数据集包含从 ArXiv 论文中提取的 2,228 个文献综述表格，用于评估语言模型将多篇论文合成为表格的能力，任务分解为 schema 生成和值生成两步。 [ev_a2d876f15337dfa522162931172c4dc9]
- [推断] QASPER 评测中，现有模型在全文问答任务上表现远低于人类（F1 差距至少 27 点），表明该任务对文档级推理要求高，且当前模型难以直接迁移。 [ev_485758ab3111644a7881713ce943f86b]
  适用范围：基于原文报告的人类与模型性能差距推断，假设评测条件一致且无额外微调。
- [推断] ArxivDIGESTables 提出 DECONTEXT EVAL 自动评估方法，用于对齐表格元素以支持可扩展评估，但原文未明确说明是否区分 oracle（有参考表）与 non-oracle（无参考表）条件下的指标差异。 [ev_a2d876f15337dfa522162931172c4dc9]
  适用范围：原文提及自动评估方法但未详述不同 oracle 条件下的指标表现，故推断其存在但未验证。
- [推断] 两篇论文均未明确说明模型是否在各自数据集上进行过训练或微调，仅报告了基线模型在测试集上的表现，因此无法判断是否需要新增标注以支持微调。 [ev_485758ab3111644a7881713ce943f86b, ev_a2d876f15337dfa522162931172c4dc9]
  适用范围：原文仅描述数据集构建与评测结果，未涉及训练过程细节，故推断训练状态未知。
- [推断] QASPER 与 ArxivDIGESTables 的任务目标、输入形式与输出结构差异显著，前者为单文档问答，后者为多文档表格合成，两者分数不具备直接可比性。 [ev_485758ab3111644a7881713ce943f86b, ev_a2d876f15337dfa522162931172c4dc9]
  适用范围：基于任务定义与数据结构的差异推断，假设评测指标与条件不可跨任务对齐。
