# 基于 QASPER 与 ArxivDIGESTables 的论文研究 Agent 评测方案对比与建议

状态：待研究者审核

- QASPER 数据集包含 5,049 个由 NLP 从业者撰写的问题，这些问题仅基于论文的标题和摘要提出，但答案需从全文中检索并引用证据。 [ev_cadc78c4a7a328825b8ee6aa2fa6bb6f]
- ArxivDIGESTables 数据集包含 2,228 个文献综述表格，这些表格综合了 7,542 篇 ArXiv 论文，旨在评估语言模型将多篇论文合成为结构化表格的能力。 [ev_b5cd17111ce07d4493062bda3c29e406]
- QASPER 任务要求回答者提供支撑答案的证据段落，且问题设计模拟了真实读者在仅阅读标题和摘要后对全文内容的信息需求。 [ev_37e52b9ce24205e023fef3140fc231de]
- ArxivDIGESTables 任务被分解为两个子任务：Schema-generation（确定共享方面）和 Value-generation（确定具体值），并开发了 DECONTEXT EVAL 方法以自动评估生成表格与人工参考表格的对齐情况。 [ev_9a7001e8e813a004c63fd110f7bb90e5]
- [推断] QASPER 适合验证单篇论文内的深度阅读理解与信息检索能力，而 ArxivDIGESTables 适合验证跨多篇论文的文献综合与结构化表达能力。 [ev_cadc78c4a7a328825b8ee6aa2fa6bb6f, ev_b5cd17111ce07d4493062bda3c29e406]
  适用范围：基于两篇论文各自定义的任务目标、输入输出形式及数据集构建方式推断得出。
- [推断] 由于 QASPER 衡量的是问答准确率（F1），而 ArxivDIGESTables 衡量的是表格生成的对齐度与有用性，两者任务目标、输出形式及评估指标完全不同，因此不能直接进行横向排名。 [ev_cadc78c4a7a328825b8ee6aa2fa6bb6f, ev_b5cd17111ce07d4493062bda3c29e406]
  适用范围：基于两篇论文中明确描述的评估方法和任务性质差异推断得出。

| 论文 / 方法 | 任务与输入输出 | 参考答案与标注 | 指标与比较条件 | 适用范围与缺口 | 证据 |
|---|---|---|---|---|---|
| QASPER | 单篇论文 QA；输入：问题+全文；输出：答案+证据 | NLP 从业者撰写问题并提供答案与证据 | F1 分数，衡量答案准确性 | 验证单篇深度理解，缺跨篇综合能力验证 | ev_cadc78c4a7a328825b8ee6aa2fa6bb6f, ev_37e52b9ce24205e023fef3140fc231de |

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取 QASPER 中 50 个单篇问题和 ArxivDIGESTables 中 20 个跨篇表格生成任务作为测试集。
  依据：结论 1, 2, 5
  假设：QASPER 和 ArxivDIGESTables 的数据格式可直接用于当前 Agent 接口；小规模样本足以初步反映 Agent 在两类任务上的基本能力
  验证计划：1. 数据准备：按上述数量随机抽取样本，确保覆盖不同难度和主题。
2. 人工检查：由领域专家对 Agent 的输出进行双盲评审，记录错误类型（如事实错误、幻觉、格式错误等）。
3. 失败计数：统计无法正确回答问题或生成无效表格的比例，设定阈值（如错误率>30% 视为失败）。
4. 迭代优化：根据失败案例调整 Agent 提示词或检索策略，重新测试直至达标。
- 针对跨篇比较能力，设计专门的‘对比维度发现’子任务，要求 Agent 从多篇论文中自动识别并列出可比属性。
  依据：结论 4, 5
  假设：Agent 具备基本的文本分析和归纳能力；ArxivDIGESTables 中的 Schema-generation 任务可作为该子任务的参考标准
  验证计划：1. 选取 ArxivDIGESTables 中 10 组论文作为输入。
2. 要求 Agent 输出可比属性列表（Schema）。
3. 将 Agent 输出与人工参考 Schema 进行比对，计算重合度和新颖性。
4. 邀请研究人员评估 Agent 发现的属性是否具有实际研究价值。
- 建立‘证据溯源’强制机制，要求 Agent 在回答任何问题时必须提供原文引用片段，否则视为无效回答。
  依据：结论 3, 6
  假设：QASPER 任务中对证据的要求是合理的，且适用于更广泛的场景；Agent 能够准确定位并提取原文片段
  验证计划：1. 在评测中加入‘无证据即失败’的规则。
2. 检查 Agent 提供的证据是否确实支持其答案。
3. 统计因缺乏证据或证据不匹配导致的失败比例。
4. 分析失败原因，优化 Agent 的检索和引用模块。

## 限制与待验证问题

- 本报告仅基于提供的两篇论文摘要及引言部分，未涵盖完整的实验设置、数据划分细节或所有基线模型结果。
- 关于产品能力的具体缺口分析是基于任务定义的推断，未经过实际产品测试验证。
- 提出的评测方案仅为理论建议，尚未执行，其有效性和可行性需进一步验证。
- 未涉及除 QASPER 和 ArxivDIGESTables 之外的其他相关评测数据集或最新模型性能。
