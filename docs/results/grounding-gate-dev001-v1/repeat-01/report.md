# 基于 QASPER 与 ArxivDIGESTables 的 Agent 评测方案对比与建议

状态：待研究者审核

- QASPER 数据集包含 5,049 个由 NLP 从业者撰写的问题，这些问题仅基于论文的标题和摘要提出，但答案需从全文中检索并附带证据支持。 [ev_e5ef94085232ab75a08fd9fa7b85fb3c, ev_bab517dd0542134a2b6d3ca1e6f398a4]
- ArxivDIGESTables 数据集包含 2,228 个文献综述表格，这些表格综合了 7,542 篇研究论文，旨在评估模型将多篇论文合成为结构化表格的能力。 [ev_8a49d66c1c5a9ad1276a592bd2e3463d, ev_66e51fc10d337681f2114a366b036e27]
- [推断] QASPER 任务要求模型在单篇论文内进行复杂推理以回答信息寻求型问题，而 ArxivDIGESTables 任务要求模型跨多篇论文提取共享属性并生成结构化表格。 [ev_e5ef94085232ab75a08fd9fa7b85fb3c, ev_66e51fc10d337681f2114a366b036e27]
  适用范围：基于两篇论文对各自任务定义的描述：QASPER 强调单篇内的复杂推理（'complex reasoning about claims made in multiple parts of a paper'），ArxivDIGESTables 强调跨篇合成（'synthesize multiple input papers into a table'）。
- [推断] 两个任务的指标不能直接横向排名，因为 QASPER 衡量的是单篇文档内问答的准确性（F1），而 ArxivDIGESTables 衡量的是跨文档表格生成的完整性与一致性（DECONTEXT EVAL 及人工评估）。 [ev_e5ef94085232ab75a08fd9fa7b85fb3c, ev_8a49d66c1c5a9ad1276a592bd2e3463d]
  适用范围：基于两篇论文使用的不同评估目标和方法：QASPER 使用 F1 分数评估问答，ArxivDIGESTables 使用 DECONTEXT EVAL 和人工评估来对齐表格元素。
- [推断] 当前产品能力中，跨论文比较的结构化输出能力（如自动生成对比表格）缺乏直接的评测依据，因为现有数据集主要关注单篇问答或特定格式的表格生成，未覆盖通用跨篇比较场景。 [ev_e5ef94085232ab75a08fd9fa7b85fb3c, ev_8a49d66c1c5a9ad1276a592bd2e3463d]
  适用范围：基于两篇论文的任务范围：QASPER 限于单篇，ArxivDIGESTables 虽跨篇但聚焦于预定义或生成的特定表格模式，未明确覆盖任意跨篇比较需求。
- [推断] QASPER 适合验证 Agent 的单篇深度阅读与信息定位能力，而 ArxivDIGESTables 适合验证 Agent 的多篇文献综合与结构化表达能力。 [ev_e5ef94085232ab75a08fd9fa7b85fb3c, ev_8a49d66c1c5a9ad1276a592bd2e3463d]
  适用范围：基于两篇论文的核心贡献：QASPER 针对单篇复杂推理，ArxivDIGESTables 针对多篇合成表格。

## 方案建议（尚未执行，待验证）

- 构建最小可执行评测组合：选取 QASPER 子集（如 100 个问题）测试单篇问答，选取 ArxivDIGESTables 子集（如 50 个表格）测试跨篇表格生成。
  依据：结论 1, 2, 6
  假设：子集能代表整体任务难度；现有工具可处理两种格式
  验证计划：划分训练/测试集，运行 Agent，计算 F1 和 DECONTEXT EVAL 分数，人工抽检 10% 结果确认质量。
- 引入人工检查机制：对每个任务的前 20 个失败案例进行人工复核，记录错误类型（如检索失败、推理错误、格式错误）。
  依据：结论 3, 4, 5
  假设：人工复核能发现自动指标遗漏的问题；失败案例具有代表性
  验证计划：设计错误分类标签体系，培训标注员，统计各类错误占比，指导后续优化方向。
- 建立失败计数阈值：若单篇问答 F1 < 0.6 或跨篇表格生成准确率 < 0.5，则判定该能力模块需重新设计。
  依据：结论 4, 6
  假设：阈值设定合理且符合行业标准；指标能反映真实能力水平
  验证计划：在测试集上运行多次实验，观察指标分布，调整阈值至稳定区间，确保评测鲁棒性。
