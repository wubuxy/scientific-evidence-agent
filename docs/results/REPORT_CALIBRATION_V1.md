# 真实报告核验与双人标注准备结果

2026-11-07。**已完成 16 份真实报告、184 次核验和 92 条自然声明的双人盲审包。人工标签尚未返回，因此语义准确率、判定器 precision/recall 和 Cohen's kappa 均未产生。** 本轮用于建立可信评测反馈，不是 skill、微调或自进化效果实验。

## 范围与机械指标

[运行前方案](../experiments/REPORT_CALIBRATION_V1.md)从官方 QASPER train 选取 12 篇新的项目开发论文，排除既有 dev50/test200 论文清单及与 dev 相同的文本哈希。4 个单论文任务、4 个双论文任务，各请求每篇论文 3 个字段，每任务从头运行两次。生产 `Runtime`、Grep、Qwen3.5-27B、20k token 上限、12 步和 300 秒在调用前固定。

| 项目 | 结果 | 含义 |
|---|---:|---|
| 计划 / 完成报告 | 16 / 16 | 保留两次完整执行 |
| 引用与结构契约通过率 | 100% | 地址、已读原文与结构有效，不代表语义支持 |
| 请求字段出现率 | 87.5% | 按任务平均，字段有内容不代表回答正确 |
| 引用来源覆盖率 | 100% | 覆盖所要求论文，不代表覆盖全部必要信息 |
| 报告生成返回用量 | 218,319 token | 每份平均 13,644.94 |
| 抽取的自然报告单元 | 151 | 包括叙述声明及表格单元格 |
| 按固定规则选取的盲审单元 | 92 | 每报告最多 6 条；条目不足不替补 |

未加入固定指南、按需 skill 或训练后的核验器，避免在建立语义测量时同时改变多个变量。官方 QA 参考没有进入生成或模型核验。保留测试集正文及答案未读取。[机械结果](report-calibration-v1/mechanical-report-scores.json)与[公开汇总](report-calibration-v1/summary.json)可审计这些分母和用量。

## 两个模型核验与格式恢复

相同 92 条声明及实际联合引用证据，分别交给 Qwen3.5-27B 和 Qwen3.5-397B-A17B，提示与采样参数一致。27B 同时是生成器，两款模型又属同一家族，不能视作完全独立的专家。

| 核验模型 | 原始计划记录 | 原始有效输出 | 返回 token | 解释长度恢复后有效输出 |
|---|---:|---:|---:|---:|
| Qwen3.5-27B | 92 | 82 | 195,941 | 92 |
| Qwen3.5-397B-A17B | 92 | 86 | 196,664 | 92 |

原始 16 个失败均仅为解释超过 800 字符。之后冻结[单独的格式恢复规则](../experiments/REPORT_FORMAT_RECOVERY_V1.md)：完整保留最多 4,000 字符的解释，所有判定字段、证据归属和行号检查继续适用。确定性重解析恢复了这 16 条，没有新增模型调用，没有改变判定或证据，原始文件未覆盖。此规则在看到失败后提出，属于事后工程修复；未来人工校准必须同时保留严格原始与恢复版本。[恢复记录](report-calibration-v1/format-recovery.json)仅公开计数和哈希。

生成与核验返回用量共 610,924 token，连接预检另计 621，总计 **611,545 token**。应用层没有结果重试；原冻结 SDK 配置允许一次传输重试。记录是返回响应的逻辑调用用量，不能独立还原失败传输的账单；详见[传输口径说明](../experiments/report-calibration-v1/transport-policy-note.json)。

模型判定、逐条分歧和一致率保存在协调者目录，人工独立提交前不公开。格式可解析、模型一致或模型更大，均不能替代人工语义正确性。

## 人工标注交付

两份包各包含离线 `start.html`、人工证据视图、自己的空白标签与[标注协议](../HUMAN_REVIEW_PROTOCOL.md)。未包含另一人的标签、候选意见、官方 QA 答案或模型方法映射。

标注者分别解压 A/B 包，打开 `start.html`，填写不同代号。逐条选择支持、矛盾或证据不足，写简短理由，点击原文行号记录关键范围；不确定的条目保留空白并说明原因。页面可保存进度、重新导入和导出 JSON。两人初次提交前不讨论单题，不查看模型意见，不让模型代填。

页面通过了桌面与窄屏浏览器检查，并用合成样例验证选项、理由、证据行、JSON 导出/导入、进度恢复及恶意文本转义。软件测试填写的标签仅在独立 fixture 中，真实两份标签仍全部为空。当前完整离线套件 **204 项通过**；CI 还会检查公开分母、成本以及人工指标保持为空的边界。

本地目录为 `D:/Ding/rc1/annotations`。A5000 的 `D:/Ding/results/report-calibration-v1` 保存数据、完整调用、盲审包和代码快照；原文与核验意见不进入公开仓库。

## 人工标签返回后的动作

先锁定 A/B 原始文件及哈希，计算原始一致率，再对分歧仲裁。之后分别校准两款模型的严格原始输出与格式恢复输出，缺失判定仍计入分母。真实标签未完成时，`claim_labels calibrate` 会拒绝空白模板。

```powershell
$env:PYTHONPATH='backend/app'
python -m research_backend.benchmarks.claim_labels calibrate --cases D:/Ding/rc1/annotations/cases.json --reviews D:/Ding/rc1/judges/qwen3.5-27b/reviews.json --labels-a path/to/completed-a.json --labels-b path/to/completed-b.json --adjudication path/to/adjudication.json --out path/to/new-calibration.json
```

对另一模型及恢复文件分别执行相同命令，不覆盖原始标签或校准结果。校准数据可用于诊断核验器错误和设计少量静态指南；最终改进效果需另选论文验证，不能把这批反馈样本同时当作确认集。
