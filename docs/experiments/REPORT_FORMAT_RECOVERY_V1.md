# 核验解释长度的离线恢复检查

2026-11-07。在两组原始核验全部完成后，观察到 27B 的 10 条、397B 的 6 条失败均为 `rationale` 超过 800 字符。原始严格结果保持不变，单独运行一次确定性格式恢复，不重新调用模型，不修订声明、模型判定或引用位置。

恢复条件只允许原始响应的唯一 schema 错误是解释文本过长；完整保留不超过 4,000 字符的解释，所有判定枚举、字段类型、跨度数量、证据归属和行范围仍须通过原检查。未知判定、额外字段、虚构证据、越界行号等错误不恢复。不截断解释，不借助参考答案或人工标签补全输出。

该规则在看过失败长度后提出，属于事后工程检查，不是新的模型能力实验。输出写入独立的 `reviews-rationale-recovery.json`，保存原始文件哈希及恢复 ID；两份原始 `reviews.json` 不覆盖。人工样本及盲审包完全相同。

未来校准同时报告严格原始覆盖率和恢复后的覆盖率，不能只选有利结果。即使恢复成功，也只说明输出可解析，无法证明语义判断正确。生产请求仍要求最多 800 字符；本次扩展仅供显式标记的离线记录恢复。
