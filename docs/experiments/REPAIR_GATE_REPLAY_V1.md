# 核验触发的普通补搜：事后轨迹回放

2026-11-06。在看过五组 dev20 结果及部分逐题答案后提出，明确属于事后探索，不能作为预注册确认结果。固定后执行一次，不筛选有利题目，不新增模型调用，不接触保留测试集。

动机：C 相对 E 的最大单题收益是纠正对论文动机的无依据推断，B 仅重答也成功；E 有 5/40 次词面 F1 退化，C 没有。原比较同时改变了是否触发、查询内容和写作时是否接收核验意见，不能把差异都解释成定向检索。

新增 G：对全部 40 个已生成上游，复用原始核验。有效核验要求修复时，选择原 E 的普通查询、回读、重答轨迹；否则保留 A。模型核验失败时保留 A，仍计核验成本。路由只读取上游和核验结果，不读取 gold 或候选答案的分数；E 的请求不含核验结果，因此可复用原请求的已观测响应。

G 的每条逻辑成本为上游 + 核验 +（触发时的 E 后续调用）。重新检查 20,000 token 上限及每个缓存请求的预算预检，不能把核验免费加到 E。无法重放的资源条件或缺失输入记为失败、仍留在 40 个分母；未知成本不计零。记录的调用耗时不能验证新策略的端到端 300 秒约束，因此本实验是 **token 约束下的缓存反事实诊断**，不是新的完整在线运行。

报告 G−E 和 C−G，按题平均两个已有重复，沿用 19 个论文连接组、5,000 次 bootstrap、seed=20261106；所有区间为事后探索。还报告保留/触发数、相对 A 的词面提升与退化数、逻辑 token。G 与 C 仍同时有查询和写作核验信息差异，不声称纯粹隔离定向查询的作用。

结果不改变原 C−E 主比较及其未通过的推进标准。无论 G 正、负或持平，都停止本轮同池策略搜索。下一阶段优先补人工语义标注和稳定的结构化输出，再决定是否投入新论文确认实验；不以本结果启动微调。

参考：[RARR](https://aclanthology.org/2023.acl-long.910/) 把修复无支撑内容与保留原输出共同作为目标；[Self-RAG](https://arxiv.org/abs/2310.11511) 使用训练得到的反思 token 控制检索与生成；[CRAG](https://arxiv.org/html/2401.15884v3) 根据检索质量触发不同处理。这里只借鉴按需处理与保留的实验问题，没有复现这三篇论文，也没有实现其训练、检索器或网页搜索机制。
