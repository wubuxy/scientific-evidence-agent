# 真实报告的核验与人工标注实验

日期：2026-11-07。上一轮短答案实验未确认定向补读优于普通补搜；本轮先建立真实报告的语义评测材料，不继续在原 20 题上筛选策略，不追加微调或自动经验更新。

## 任务与冻结

从已下载的官方 QASPER v0.3 **train** 中，选择 12 篇本项目尚未用于 Agent 实验的论文。排除既有 dev50 和保留 test200 清单中的全部论文 ID，并排除与 dev 文本哈希相同的论文。仅读取保留测试的 ID 清单，不读取其正文和答案。它们是本项目的新开发论文，不是对模型预训练数据未知的隐藏测试。

沿用现有文本可回答性预处理，排除依赖表图、证据无法映射、非弃答缺少证据等样例。至少含 3 道合格问题的论文按 `SHA256("report-calibration-v1:20261107:" + paper_id)` 排序取前 12；每篇问题按同样规则排序取 3。所有合格答案类型均可入选，不依赖模型历史得分选样。前 4 篇各组成单论文任务，后 8 篇两两组成双论文任务，共 8 任务、36 个请求字段。问题使用原始人工问题，字段统一命名 Q1/Q2/Q3，避免把长问题当作 schema 字段名。

两个独立完整重复，共 **16 份报告尝试**。使用工作台实际 `Runtime`、`report-grep`、`qwen3.5-27b`、temperature 0.1、关闭 thinking，单次上限 20,000 token、12 步、300 秒，并发 2。名义生成上限 320,000 token。每次重新检索和回读，不共享历史答案。生成进程只接收 inputs，不接收 gold；官方参考仅在独立词面诊断阶段使用。

输出使用短目录 `D:/Ding/rc1/run001`。运行前离线检查全部资料导入、模型连接和 JSON 工具调用。模型预检用量独立记账。题目、代码、模型、预算和分母冻结后不改；失败保留，不选择性补跑。

## 自然声明抽样

从原始报告抽取带限定语的叙述声明及每个表格单元格。对每份报告最多抽 6 条：先按固定哈希顺序各取最多 3 条叙述声明和 3 条请求字段 Q1/Q2/Q3；不足时用其余单元格或声明按哈希补齐。选择发生在核验之前，不依据模型意见选难例，也不人为编辑声明。

最多 **96 条自然报告单元**；失败报告或条目不足不从其他任务替补。报告失败仍在 16 个任务分母，不能因为无法生成声明而消失。声明之间以及同论文两次重复不独立，人工标注结果仅解释这个报告样本分布。

## 两个自动核验对照

在完全相同的声明与本次实际引用窗口上，分别调用 `qwen3.5-27b` 与更大的 `qwen3.5-397b-a17b`；使用现有联合证据核验提示、schema、temperature 0.1，关闭 thinking。每个模型只运行一次，整体上限各 750,000 token；所有格式、引用跨度、预算和调用失败计入覆盖率。不得把同一模型重试到成功后替换首个结果。

27B 也是报告生成器，存在自我偏好风险；397B 虽是更大对照，仍属同一家族，不能宣称完全独立。两者只是候选判定，大小不代表正确性。核验失败、两者分歧与同判均保留；人工包不按分歧抽样。每个候选保留原始响应、证据跨度和成本。

报告程序契约通过率、请求字段出现率、全部失败、真实 token、核验覆盖率和两模型一致率。可另报告官方短答案的字段 token F1 作为词面诊断；不得将字段出现率、模型同意率或词面 F1 称为语义正确率。

## 人工真值与成功标准

用户已确认可安排两位独立标注者。两人仅获得同一批打乱顺序的自然声明、原始问题、实际联合引用证据、空白标签及操作说明；模型、轮次、候选结论、官方 QA 答案和另一人的意见均隐藏。两人独立提交后锁定原始文件，再做分歧仲裁。沿用[标注协议](../HUMAN_REVIEW_PROTOCOL.md)，不让模型替代人工填写。

拿到完整人工标签后再计算 Cohen's kappa、各类 precision/recall/F1、错误支持率和模型间配对差；缺失判定保留分母。没有人工标签时这些值为 null，不自动把模型意见升级为 gold，也不自动采用较大模型。

本轮完成标准是：全部 16 个计划尝试有记录、自然声明按冻结规则选样、两个核验对照的全部计划单元有记录、两份可独立使用的盲审包可导出标签、成本与失败可审计。语义有效性结论等人工标签，不以模型一致率通过任何训练或上线门槛。

后续静态 skill / 普通重答 / 普通搜索对照须单独冻结。先用这批人工反馈定位错误类型和校准判定器，再用另选论文检验改进，不把本轮校准数据同时当作最终确认集。
