# 证据核验器的数据对照实验计划

日期：2026-11-06。状态：**根据已完成诊断形成的下一轮方案，尚未启动新训练，尚未冻结新增数据与独立测试 ID**。研究目标是判断标签质量、难例覆盖和支持判定规则分别能解释多少错误，而非预设微调一定是最终方案。依据见[数据诊断](../results/VERIFIER_DATA_DIAGNOSIS.md)。

## 数据和标注准备

先复核已准备的 83 对样本。两位人工标注者独立判断，仅看到声明和本次提供的摘要；不显示原标签、模型输出和外部审计结论。记录 supported / contradicted / insufficient、证据句位置、数量与范围等限定，以及无法判断的原因。对分歧进行仲裁，报告原始一致率、Cohen's kappa 和仲裁数量。LLM 意见只作为候选意见，不充当第二位人工标注者。

任务判据固定为“所提供证据是否支持完整声明”。没有显著差异不自动证明零效应；研究对象、结局、比较组或阶段不匹配时，需要明确区分矛盾与证据不足。公开审计所列的更正也遵守这套判据，不能照单全收。只按 claim–document 对记录更正，保留原始标签、建议标签、最终标签、原因与来源。

对训练、校准、评分做三个独立版本：原始基准；经人工仲裁的更正层；新增目标域数据。重评分所有模型时使用相同更正层，保留全部样本分母和原始结果。当前 v1/v2 测试已观察，后续用于诊断和开发；在这些样本上调参后不能再称其为独立验证。

## 第一阶段 标签修正是否改变训练结果

固定 Qwen2.5-7B-Instruct BF16、LoRA q_proj/v_proj、rank 8、alpha 16、dropout 0.05、学习率 2e-4、batch 1、累积 4、128 步、输入上限 1536、三个原定种子。冻结样本 ID 和每个种子的抽样顺序，使两个条件实际见到相同的 512 对样本。

| 条件 | 唯一差异 | 可回答的问题 |
|---|---|---|
| A 原始标签 | 沿用 535 对原始训练标签 | 匹配的复跑对照 |
| B 仲裁后标签 | 对同一批样本应用确认的训练更正 | 更正监督是否减少错误支持 |

不同时改变 rank、提示、训练步数、采样权重或加入新样本。未达成人工一致的候选暂不修改。两组都在同一份仲裁后开发评分集上比较，并附原始 gold 口径；不能用 A 的原始 gold 成绩与 B 的更正 gold 成绩相减。

共 6 次训练。按上一轮约 214 秒/次估计，纯训练约 22 分钟；底座加载、重载、评估及环境状态另计，预计预留 1–2 小时单卡时间。每个条件从原始底座开始，不在旧适配器上继续训练。三种子全部报告，不选择最好一次。

这一阶段回答训练标签的局部因果问题，旧开发集成绩不作为泛化确认。如果修改很少、效果接近零或不同种子方向不一致，就报告有限影响，继续检查难例覆盖和判定方式；不通过追加训练轮次追求正结果。

## 第二阶段 固定权重检查判定规则

对未微调 7B、A、B 和原生 MiniCheck 比较默认支持决策与独立校准的支持阈值。每个方法单独选择阈值，选择规则相同：在校准集经验错误放行率不高于 5% 的条件下最大化支持召回；没有可行的非空放行集合则明确报告全部弃答。

同时报告支持精确率、召回率、错误放行率、AUROC、接受比例及其按论文连接组重采样的区间。保留三分类 argmax 指标；高于阈值的支持与原三分类结果是两套明确决策，不把未通过支持阈值直接当成“矛盾”。不支持分支可继续保留 contradicted / insufficient 或进入人工复核。

旧 65 对校准集仅用于开发诊断。目标域校准集需独立按论文划分，优先积累至少 100 条经人工确认的不支持样本，另含支持样本；达不到时报告校准样本不足，不把经验 5% 写成真实风险保证。保存完整 A/B/C logits、三类分数、类别词概率质量、输入长度及实际支持阈值，方便排查饱和与类别偏置。

## 第三阶段 区分新增数据和定向难例的价值

只有在标签定义和开发流程稳定后开展。新增内容只来自训练论文池，与校准和未来测试论文保持连接组隔离。围绕数量、对象、对照组、否定、因果、范围和研究阶段构造最小差异样本；证据相同而声明只改一个关键条件，并保留原始样本。所有新增样本都需要可回读证据和人工核验，不能仅以生成模型自己的判断赋标签。

| 条件 | 数据 | 训练预算 |
|---|---|---|
| C 重复训练对照 | 仲裁后的原始 535 对，按固定顺序循环 | 256 步 |
| D 普通扩充 | 同一训练集 + 300 条普通改写样本 | 256 步 |
| E 定向难例 | 同一训练集 + 300 条最小对照样本 | 256 步 |

D/E 的新增数量、论文来源池、类别配额和长度范围匹配；按父声明与论文分组，防止近似改写跨集合。两组都保留支持样本，避免“更保守”只是学会全部拒绝。C/D/E 均使用同一底座、精度、提示、三个种子及相同 optimizer 步数，记录实际输入 token 总量，避免将相同样本数冒充相同 token 成本。

主要比较 E−C 判断新增数据整体收益，E−D 判断定向构造相对普通扩充的收益。若 E 与 D 相当，应归因为新增数据而非宣称难例构造机制有效。若只是延长训练有效，也要通过 C 明确展示。

类别均衡采样、改变 loss 权重和 64/128/256 步曲线作为后续独立消融，逐项更改，不与 A/B 标签对照混合。当前训练日志不足以诊断过拟合，曲线应固定评估数据，不用不同 minibatch loss 代替验证曲线。

## 目标域验证与强基线

在新的 NLP 论文及真实 Agent 输出上建立独立测试，目标为至少 200 条自然产生的声明、至少 40 篇论文，保留自然类别分布和实际引用窗口。另建按错误类型覆盖的诊断集；合成或人工改写样例单列，不能补入真实准确率分母。自然测试中的不支持样本过少时，应扩充标注或报告区间过宽。

原始底座、最终候选及 MiniCheck 使用同一证据，MiniCheck 只参与二分类比较。再补一个独立架构的三分类 NLI 基线；其公开训练语料、SciFact 暴露、上下文上限和标签映射必须先核实。若使用已训练过 SciFact 全训练集的权重，不能与本项目的论文隔离声明混为一谈；若上下文不足，报告共同短输入子集或单独定义窗口策略，不静默截断。

所有新论文的 ID、文本哈希、划分与标注协议在预测前冻结。测试标签由评分端保管，不用于挑提示、阈值、样本构造方式、checkpoint 或种子。QASPER 200 题保留集继续保留，本计划使用独立的 claim-level 数据。

论文/声明连接组是统计重采样单位，三次训练不是三倍独立样本。最终确认性主比较及多重比较校正数量要在新测试运行前固定；事后增加的切片均标为探索性。样本量不足时不承诺证明 3–5 个百分点差异。

## 决策和结束条件

采用的依据是目标域上的错误放行、支持召回、三分类用途和成本的共同表现。某个阈值下全拒绝不能算成功；某个总体分数提高也不能覆盖错误支持增加。

如果 B 的效果不稳定，记录标签更正影响有限；如果 E 没有优于普通扩充或重复训练，不继续宣称定向数据方法有效；如果现成核验器在所需错误放行约束下已更合适，则采用现成组件，把研究重心转向证据读取与补读策略。完整 Agent 的质量收益仍需另做“无核验、仅重答、核验后补读”的受控比较，不能由模块分类成绩推断。
