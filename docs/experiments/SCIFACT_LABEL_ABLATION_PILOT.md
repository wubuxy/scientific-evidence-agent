# SciFact 公开标签更正建议的训练对照

日期：2026-11-06。实验在正式预测前冻结本协议、代码、数据文件和种子顺序。83 对样本尚未完成人工盲审，本轮用公开审计建议开展**探索性标签干预**，不称为经过人工仲裁的训练或新测试。来源为 [Sylvestre 的 BioNLP 2026 审计](https://aclanthology.org/2026.bionlp-1.9.pdf)，固定建议文件及许可见[来源清单](../dataset-manifests/scifact-audit-bionlp2026/provenance.json)。

## 研究问题与条件

在模型、输入、顺序和更新次数相同时，将 7 条训练标签替换为公开审计建议，能否改变对未参与训练论文的分类表现和错误支持？现有 v2 的 128 对评估样本已经被观察，只用作开发诊断。

| 条件 | 训练数据 | 其余设置 |
|---|---|---|
| raw | 原始 535 对标签 | Qwen2.5-7B-Instruct BF16 LoRA |
| proposed | 同一批 535 对，仅替换 7 个标签 | 与 raw 完全相同 |

7 个训练 claim ID 为 164、165、79、1297、576、933、1036，实际 claim–document 对和更正方向写入 overlay。仅匹配外部建议的原始标签和文档范围，未标注的其他被引摘要不改变。声明 597 的不明确文档级建议不参与训练或默认更正评分。

沿用冻结 v2 的训练函数：rank 8、alpha 16、dropout 0.05、q_proj/v_proj、AdamW、学习率 2e-4、weight decay 0.01、8 步 warmup 后线性衰减、梯度裁剪 1、batch 1、累积 4、128 次更新、最大 1536 tokens、不截断。每次实际见到 512 对，两个条件的样本 ID 和顺序相同。种子为 20261106、20261107、20261108；运行顺序是 raw06、proposed06、proposed07、raw07、raw08、proposed08，六次都从原始底座加载。

不挑最佳种子、checkpoint 或根据评估结果追加步数。保存适配器后从原底座重载再预测。沿用同一环境和 BF16，不自动改成量化训练。资源异常保留原日志和失败分母；若必须修改代码，另行冻结并明确区分版本。

## 输入与评分隔离

沿用 v2 的 65 对校准、128 对已观察评估、16 对合成挑战与 32 对空证据诊断。生成进程只读取 inputs 和训练标签，跳过所有 labels 文件的读取和哈希检查；独立评分进程读取评价标签。保存完整 A/B/C logits、概率、类别词总概率质量、输入 token 和时间。

原始 7B BF16 与 MiniCheck 使用 v2 已冻结、同输入的 482 条基线预测，标注为归档参考，不计入本轮 GPU 运行。六次新训练产生 6×241=1446 条预测。输入、权重、参考预测和代码哈希在 plan 中固定。

## 评价口径与统计

三个 gold 视图分别报告，任何比较都在相同视图内进行：

1. original：原始 SciFact gold。
2. published：应用范围明确的 1 条校准建议和 6 条评估建议，仍是单人公开审计建议。
3. doc597：在 published 上额外将评估对 597/12779444 视为 insufficient，作为单独的文档范围敏感性情景。

每个视图报告三分类 Macro F1、各类 precision/recall、混淆矩阵、支持精确率、支持召回、非支持误判支持率、AUROC、缺失数量。MiniCheck 只参与二分类。缺失预测保留在分母、计入分类错误；任何条件不完整时不计算差值区间或声称干预有效。

主要差值是 proposed 三种子均值减 raw 三种子均值：**错误支持率和三分类 Macro F1**。在 original 与 published 两个视图形成四项预定比较。按 103 个论文/声明连接组配对 bootstrap 5000 次，固定随机种子 20261109；报告普通 95% 和四项 Bonferroni 校正后的 98.75% 区间。三个训练种子不当作三倍评估样本。doc597 只报告敏感性点估计；支持召回区间为次要描述。

支持阈值只由对应视图的校准标签确定：在经验错误支持率不超过 5% 的候选中最大化支持召回；并列时优先更少假阳性，再选择更高阈值。允许全部弃答，必须同时报告接受比例与召回。阈值不从评估结果选择，不把小校准集的经验 5% 当作总体保证。默认三分类判断与阈值二分类判断分开报告。

## 结束与解释

完成六次训练、固定预测、三种 gold 视图、阈值对照和配对分析后结束本轮。无论方向如何都报告全部种子。如果更正建议影响很小或方向不一致，结论是这 7 条干预不足以解释当前问题；如果改善，也只支持此数据范围内的标签干预效果，不证明公开建议是最终真值、当前模型可自动批准声明或完整 Agent 有收益。

人工仲裁后的训练、目标域自然声明测试和新增难例训练仍遵循[后续方案](VERIFIER_DATA_EXPERIMENT_PLAN.md)，不以本轮代理实验冒充完成这些阶段。
