# A5000 轻量证据核验器 pilot v1

日期：2026-11-05。状态：先固定协议与代码，再生成划分清单；清单、模型哈希和代码提交固定后开始推理与训练。本协议不使用 QASPER 的 200 题保留测试集，不调用付费模型 API。

## 要回答的问题

在相同基础模型、4-bit 量化、输入与判定方式下，少量有标签的训练是否能提高“声明是否被指定论文摘要支持”的判断质量？再检查这种改进是否保留在项目已有的合成角色、数字、否定和阶段挑战例上。

这是核验模块的受控实验，不是完整 Agent 的准确率实验。研究成功后，仍需单独验证检索、补读和完整报告上的收益。

## 数据与隔离

使用 [SciFact 官方数据](https://github.com/allenai/scifact)，下载地址为作者提供的 `https://scifact.s3-us-west-2.amazonaws.com/release/latest/data.tar.gz`。本次原始文件 SHA256：`11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`。官方 train 有 809 条 claim，dev 有 300 条 claim，摘要库有 5,183 篇文献。

依据 [官方格式说明](https://github.com/allenai/scifact/blob/master/doc/data.md)，构造 claim—指定被引摘要对：有一致的 SUPPORT / CONTRADICT 标注时映射 supported / contradicted；被引摘要未被标注为含证据时映射 insufficient。只使用实际被引摘要，不随意把随机错配摘要当成真实负例。输入是 claim、标题与完整编号摘要，不含标签或 gold rationale。

1. 官方 dev 的全部论文、重复摘要和重复 claim 从训练候选中排除；不把公开 dev 称为隐藏测试集。
2. 官方 train 候选按共享论文、重复文本与共享 claim 的连接组划分。组按固定种子散列排序，先选校准集，再选训练集；跨组不共享论文或 claim。
3. 训练上限 768 对，校准集目标 64 对，最终测试目标 128 对。按完整连接组取样，到目标即停，允许因保留完整组略超目标；实际 ID、数量、类别与排除项写入 manifest。
4. 测试来自官方 dev。原始全文超过固定 1,536-token 输入上限时排除，记录数量，不静默截掉证据。依据长度过滤在模型预测前完成。
5. 训练标签可用于训练；校准 / 测试输入与 gold 分文件。推理程序不接收测试 gold 路径。现有 16 条项目合成例单独报告，不加入训练，也不当成真实场景准确率。

选择 SciFact 的理由是已有专家编写的声明与证据标注，能够避免把模型自造标签当成真值。它主要来自生物医学摘要，不能据此声称已经验证 NLP 全文报告的语义正确性。[数据论文](https://aclanthology.org/2020.emnlp-main.609/)

## 模型与条件

基础模型固定为 [Qwen2.5-1.5B-Instruct](https://modelscope.cn/models/Qwen/Qwen2.5-1.5B-Instruct)，通过 Qwen 官方 ModelScope 仓库下载，记录全部运行必需文件哈希；仅加载 safetensors，关闭远程代码执行。

| 条件 | 处理 |
|---|---|
| 多数类基线 | 只使用训练集标签频次，预测固定类别 |
| 原模型 | NF4 4-bit 基础模型，不训练 |
| QLoRA | 同一量化基础模型，三个预定随机种子分别训练 |

统一提示要求只按给定摘要判定，A / B / C 分别表示 supported / contradicted / insufficient。确认三个标签都是单 token，比较下一 token 对三个候选的 logits，固定 argmax，不调测试阈值。这是受限三选一分类，不等于自由 JSON 输出能力。另记录候选 token 的原始概率质量，避免把三类归一化概率误称为完整生成置信度。

训练配置：种子 `20261105 / 20261106 / 20261107`；LoRA rank 8，alpha 16，dropout 0.05，目标 q_proj / v_proj；NF4 + double quant，BF16 计算；micro-batch 1，梯度累计 4；AdamW，学习率 2e-4，weight decay 0.01，梯度裁剪 1；128 个优化步骤，前 8 步 warmup，其后线性衰减；开启 gradient checkpointing。监督目标仅为答案类别 token，不训练全文复述。每个种子使用最后一步，不按测试分数挑 checkpoint。

现有驱动 537.13 下使用独立环境的 PyTorch 2.7.1/cu118；基础 GPU BF16 矩阵计算与反向传播已通过。模型与数据位于 `D:\Ding`，环境位于 Ubuntu 用户目录。模型、数据、缓存、结果分别存放，训练过程不改 Windows 驱动。

## 指标与判定

主要指标是三类 macro F1，辅以各类 precision / recall、supported precision、无支持样本被误判 supported 的比例、混淆矩阵、每例延迟、训练耗时和峰值显存。

完整报告三个种子的结果及均值；配对 bootstrap 按测试中共享论文 / claim 的连接组抽样，计算三种子平均 F1 相对原模型的差，5,000 次抽样、95% 区间。重复种子不当成独立文献样本。失败 / 缺失预测计错，不从分母删除。

预定 pilot 质量门槛：平均 macro F1 比原模型提高至少 3 个百分点、配对区间下限大于 0，且“无支持样本误判 supported”的比例不比原模型增加超过 2 个百分点。门槛只是本轮工程选择标准，不保证当前规模具有足够检验效力。未达门槛时报告 null 或不确定，不追加搜索直到得到正结果。

额外诊断：原模型和微调模型在无证据输入上应主要判 insufficient；项目 16 条合成例分别列出前后预测，检查迁移退化。这些诊断不替代主要测试集，不事后更换主要指标。
